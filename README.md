DESCRIPTION: This project is a Big Data Analysis system developed using Python and PySpark. The main objective of this project is to analyze a large Netflix movies dataset and demonstrate scalability using distributed data processing techniques provided by Apache Spark.

The project begins by importing essential PySpark libraries and creating a Spark Session for distributed computing. The Netflix Popular Movies dataset is loaded from a CSV file into a PySpark DataFrame for efficient large-scale data processing.

Basic dataset operations such as displaying records, checking schema, and counting total records are performed to understand the structure of the dataset. Data preprocessing techniques such as removing null values are also implemented to improve data quality.

Several analytical operations are performed on the dataset, including identifying the most popular movies, calculating average movie ratings, analyzing the highest-rated movies, and counting movies based on language and genres. Aggregation functions, sorting, grouping, and filtering techniques are used extensively during analysis.

To demonstrate scalability and performance optimization, PySpark features such as caching and partitioning are implemented. The processed analysis results are also saved into output files for future use.

The project provides practical experience in Big Data Analytics, distributed computing, and scalable data processing using PySpark.
